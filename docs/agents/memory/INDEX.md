- [Dart num.tryParse Non-Finite Conversion Trap](./defect-dart-num-tryparse-non-finite.md) — num.tryParse("Infinity") returns double.infinity; invoking toInt() throws unhandled UnsupportedError unless guarded with isFinite.
- [Mocktail Sequential Verification Counter Reset](./defect-mocktail-sequential-verify-semantics.md) — verify().called(count) consumes unverified calls since the last verification, resetting the counter rather than checking lifetime calls.
